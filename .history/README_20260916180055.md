# Wordy

This is my first Python project EVER. And first of all I would like to thank Mosh from Youtube for teaching me Python. He helped me learn about loops and variables in a very easy method. Wordy is a terminal based guessing game that is inspired by Wordle. And the main goal is to figure out the 5 letter word in 6 or less tries. 

This recieves its data from Datamuses Api which gets English words that match the requirements and it matches and validates your answers each time you write in that terminal.

## Features

- Randomly selects a random 5 letter word
- Gets real time validation from a real dictionary powered by something called Datamuse, which is an API
- There is coloured feedback after every guess
- Play-again option
- Internet powered selection of words
- It handles the duplication of letters amazingly
- There is an on-screen keyboard that tracks the letters that are chosen each time

## How it works

So when the game starts this happens:

1. Wordy requests a list of common 5 letter words that are in the English dictionary and it is powered from Datamuse

2. A random word is chosen as the secret answer

3. The player only has 6 chances

4. After every guess the game gives feedback that is on screen

### Feedback Colours

**Colour**       **Meaning**
Green              Letter is correct and in the right position
Yellow             Letter is correct but not in the right position
Gray               Letter is wrong and in the wrong place

***For example:***

**Secret_word**: Crane
**Guess**: Cable

**Result**:

🟩 ⬜ 🟨 ⬜ 🟩

- So C is correct
- B is not in the word
- A is in the word but in the wrong position
- L is not in the word
- And finally E is correct

## APIS Used

**Datamuse API**
This is used for generating a pool of common english words that are 5 letters long:

*Purpose:*
- Find 5 letter words
- Get frequency scores
- And filters out words that are uncommon

**Free Dictionary**
Used to verify if the plays word actually exists and is not fake: 

*Purpose:*
- Prevents wrong answers
- Improves the gameplay quality for the user.
